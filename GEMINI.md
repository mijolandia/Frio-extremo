# 🤖 Frío Extremo + Google Gemini = Script Profesional

## ¿Cómo se creó este proyecto?

**Frío Extremo** fue desarrollado completamente usando **Google Gemini**, el asistente de IA de Google.

### 🛠️ Proceso de Desarrollo

```
IDEACIÓN → GENERACIÓN → OPTIMIZACIÓN → DOCUMENTACIÓN → PUBLICACIÓN
   ↓          ↓             ↓              ↓               ↓
¿Qué      Gemini crea   Refinamiento   Documentos   GitHub Pages
scripts?  código Skript  de features    completos    en vivo
```

✅ **Scripts Skript** - Código 100% funcional

## 🚀 Cómo Gemini fue usado

### 1. Generación de Lógica
```
PROMPT: "Crea un script Skript de tienda con compra/venta dinámico"

```

### 2. Optimización
```
PROMPT: "Optimiza este código para mejor performance"
GEMINI: Elimina redundancia, mejora bucles, agrega cache
```

### 3. Documentación
```
PROMPT: "Escribe guía de instalación en español"
```

### 4. Debugging
