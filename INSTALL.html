📖 Guía de Instalación - Frío Extremo

Pasos completos para instalar todos los scripts en tu servidor PaperMC 1.21.11

✅ Requisitos Previos

Tu servidor debe tener:

  • PaperMC 1.21.11 (versión del servidor)
  • Skript 2.15.4+ (plugin Skript actualizado)
  • SkBee 3.25+ (extensión de Skript)
  • Vault (para economía)
  • LuckPerms (para gestionar permisos - RECOMENDADO)
⚠️ IMPORTANTE: Todos los scripts utilizan el nombre [NOMBRE_SERVIDOR] como placeholder. Debes reemplazarlo con el nombre de tu servidor ANTES de instalar.

Paso 1: Descargar los Scripts

Descarga todos los archivos .sk desde GitHub:

URL del repositorio:

https://github.com/mijolandia/Frio-extremo

O descargalos uno por uno desde la web.

Paso 2: Preparar los Scripts

Antes de copiar al servidor:

  1. Abre cada archivo .sk en un editor (VS Code, Notepad++, etc)
  2. Presiona Ctrl + H (Buscar y Reemplazar)
  3. Busca: natureland
  4. Reemplaza con: [TU_SERVIDOR] (sin espacios, minúsculas)
  5. Haz clic "Replace All"

Ejemplo:

natureland.tienda.admin  →  miservidor.tienda.admin
natureland.spawn         →  miservidor.spawn
natureland.bolsa.admin   →  miservidor.bolsa.admin

Paso 3: Copiar Scripts al Servidor

Ubicación correcta:

plugins/Skript/scripts/

Copia TODOS los archivos .sk en esa carpeta.

Estructura esperada:

plugins/Skript/
├── scripts/
│   ├── tienda.sk
│   ├── Bolsa.sk
│   ├── rtp.sk
│   ├── Spawn.sk
│   ├── pocion.sk
│   ├── mobs.sk
│   ├── calor-extremo.sk
│   ├── Avisos.sk
│   ├── reparador.sk
│   ├── limpieza.sk
│   ├── mundos.sk
│   └── ayuda.sk
└── config.yml

Paso 4: Recargar Skript en el Servidor

Conectate al servidor y ejecuta en la consola o ingame:

/sk reload all

O si quieres recargar un script específico:

/sk reload tienda

Paso 5: Configurar Permisos (LuckPerms)

Si usas LuckPerms, otorga permisos a tus jugadores/grupos:

Comando Efecto
/lp group admin permission set [TU_SERVIDOR].* Todos los permisos para admins
/lp group default permission set [TU_SERVIDOR].tienda.usar Todos usan la tienda
/lp group vip permission set [TU_SERVIDOR].rtp.usar VIPs pueden usar RTP
/lp user Minecraft_323 permission set [TU_SERVIDOR].admin User específico es admin

Paso 6: Verificar Instalación

Comprueba que TODO funciona:

  1. Ejecuta /spawn - Deberías ir al spawn
  2. Ejecuta /rtp - Te teletransporta a ubicación aleatoria
  3. Ejecuta /menu - Abre el menú de ayuda
  4. Abre /pociones - Muestra guía de alquimia
✅ ¡Si todo funciona, ya está instalado!

🔧 Solucionar Problemas

❌ Error: "Script no se carga"

Soluciones:

  • Verifica que SkBee esté instalado: /plugin skbee
  • Recarga Skript: /sk reload all
  • Revisa la consola por errores de sintaxis
  • Comprueba que los permisos estén bien reemplazados

❌ Error: "No tienes permiso"

Soluciones:

  • Verifica que los permisos se reemplazaron correctamente en el script
  • Usa LuckPerms para otorgar permisos: /lp user [nombre] permission set [TU_SERVIDOR].*
  • Reconectate al servidor para que se apliquen permisos

❌ Los comandos no funcionan

Soluciones:

  • Asegúrate de que LuckPerms esté instalado
  • Verifica que Vault esté instalado para economía
  • Reemplaza "natureland" en TODOS los archivos .sk
  • Ejecuta: /sk reload all
