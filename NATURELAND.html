⚙️ Personalizar Frío Extremo

Guía completa para reemplazar referencias de servidor y personalizar los scripts

❓ ¿Qué es "Natureland"?

"Natureland" es el nombre del servidor original donde se desarrollaron estos scripts.

Cuando descargas los archivos, verás referencias a "natureland" en:

  • Comentarios de cabecera de archivos
  • Variables del servidor (ej: {natureland.spawn})
  • Permisos (ej: natureland.tienda.admin)
  • Mensajes de broadcast

🔄 Cómo Reemplazar "Natureland"

Método 1: En Editor de Texto (RECOMENDADO)

  1. Abre un archivo .sk en tu editor (VS Code, Notepad++, Sublime Text)
  2. Presiona Ctrl + H (Buscar y Reemplazar)
  3. En "Buscar" escribe: natureland
  4. En "Reemplazar" escribe: miservidor (o tu nombre)
  5. Haz clic en "Replace All"
  6. Repite para TODOS los archivos .sk

⚠️ Importante: El nombre debe ser:

  • Sin espacios (usa guiones si quieres: mi-servidor)
  • Minúsculas (los permisos en Minecraft son así)
  • Único (no uses nombres de otros servidores)

Método 2: Buscar y Reemplazar en Lote

Si tienes muchos archivos, usa un script bash:

for file in *.sk; do sed -i 's/natureland/miservidor/g' "$file" done

Esto reemplaza "natureland" en todos los .sk automáticamente.

📋 Ejemplos de Reemplazo

Antes (Original):

options:
    prefix: &8[&a&lNATURE&e&lLAND&8]
    perm_admin: natureland.tienda.admin
    
on join:
    send "&8[&6NatureLand&8] ¡Bienvenido al servidor!"

Después (Personalizado):

options:
    prefix: &8[&a&lMI-SERVIDOR&8]
    perm_admin: miservidor.tienda.admin
    
on join:
    send "&8[&6Mi Servidor&8] ¡Bienvenido al servidor!"

✅ Verificar Cambios

Después de reemplazar, verifica:

  1. Abre cada archivo .sk y usa Ctrl + F
  2. Busca "natureland" (sin mayúsculas)
  3. NO debería encontrar coincidencias (excepto en comentarios si quieres)
  4. Busca tu nuevo nombre (ej: "miservidor")
  5. Deberías ver varias coincidencias

⚠️ Errores Comunes

❌ "Permiso no reconocido"

Causa: Olvidaste reemplazar "natureland" en algún archivo.

Solución: Busca natureland en todos los .sk y reemplaza.

❌ "Comando no funciona"

Causa: El comando tiene variables sin personalizar.

Solución: Verifica que reemplazaste correctamente {natureland.variable}

❌ "Script no se carga"

Causa: Error de sintaxis por reemplazos incompletos.

Solución: Revisa la consola del servidor para ver el error exacto.
